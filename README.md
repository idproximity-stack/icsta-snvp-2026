# ICoAILO 2026 Conference Landing Page Template

Template landing page konferensi akademik / ilmiah berbasis referensi resmi [icoailo.org](https://icoailo.org/).

## 📁 Lokasi File
- File utama: [`index.html`](index.html)

## 🚀 Cara Menjalankan
1. **Langsung di Browser**: Klik dua kali file `index.html` atau buka melalui browser pilihan Anda (Google Chrome, Edge, Firefox).
2. **Local Server (Opsional)**:
   ```bash
   # Menggunakan Python
   python -m http.server 8000
   
   # Atau menggunakan Node / npx
   npx serve .
   ```

## 🛠️ Fitur & Komponen yang Tersedia
- **Announcement Banner**: Informasi prosiding IEEE Xplore & kontak email.
- **Sticky Navbar**: Navigasi responsif dengan toggle menu mobile (hamburger menu).
- **Hero Section**: Judul konferensi, tema SAFE AI, tanggal, lokasi hybrid, dan tombol CTA.
- **Live Countdown Timer**: Penghitung mundur otomatis menuju batas akhir pengumpulan paper.
- **Highlight Badges**: Total track, IEEE Xplore, format hybrid, indeks Scopus.
- **About Section**: Penjelasan seputar konferensi & profil CoE AILO Telkom University.
- **Important Dates**: Timeline visual deadline paper submission (Round 1 & 2), notifikasi, camera-ready, dan hari konferensi.
- **Conference Tracks / CFP**: 4 kategori track riset (Machine Learning, Optimization, Cyber Security, Applied AI) beserta rincian subtopik.
- **Keynote Speakers**: Kartu profil pembicara dengan foto, afiliasi, dan judul materi.
- **Interactive Registration Pricing**: Tombol switch mata uang interaktif (**IDR** untuk Domestik vs **USD** untuk Internasional).
- **Author Submission Guidelines**: Panduan 4 tahap (Template IEEE, Blind Review, CMT Portal, Camera-Ready).
- **Venue & Hotel**: Informasi akomodasi (Grand Orchardz Hotel Kemayoran, Jakarta & Hybrid Zoom).
- **Organizers & Co-Sponsors**: Logo Telkom University, IEEE Indonesia Section, dan CoE AILO.
- **Interactive FAQ**: Pertanyaan umum seputar presentasi online, publikasi IEEE, dan aturan plagiasi.
- **Footer**: Kontak sekretariat, form newsletter, dan tombol *back-to-top*.

## 🎨 Teknologi yang Digunakan
- **HTML5** murni.
- **Tailwind CSS** (via CDN).
- **Font Awesome 6** (via CDN untuk ikon).
- **Google Fonts** (Inter & Outfit).
- **Vanilla JavaScript** (Countdown timer, currency toggle, mobile navbar drawer).
